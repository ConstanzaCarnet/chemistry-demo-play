# Decisiones de arquitectura (ADR)

Un **ADR** (*Architecture Decision Record*) registra una decisión importante: el contexto, qué se decidió, qué alternativas se descartaron y qué consecuencias trae. No se borran: si una decisión cambia, se escribe un ADR nuevo que "reemplaza" al anterior.
